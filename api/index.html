    API reference¶

    Estimators¶

    phasmanet.PhasmaNetRegressor ¶

    PhasmaNet for (multi-output) regression.

    Targets are standardised internally. Regression options: loss ("mse" or "huber"), huber_delta (1.0, in units of the standardised target), weighting ("none", "by_hist" or "inverse_freq"; see below), hist_bins (20), wmin (0.2), wmax (5.0), calibrate (False; monotonic PCHIP calibration fitted on the validation split, single-output only), calibration_bins (60), calibration_min_bin (20).

    Weighting schemes over a histogram of the (first) training target: "by_hist": the formula of the paper's training script, w = clip(1 / bin_count, wmin, wmax), then normalised to mean 1. "inverse_freq": w proportional to 1 / bin_count normalised to mean 1 first, then clipped to [wmin, wmax] and renormalised, so rare target ranges are up-weighted.

    Examples:

    >>> from phasmanet import PhasmaNetRegressor
>>> reg = PhasmaNetRegressor(num_stages=4, max_epochs=300, random_state=0).fit(X_train, y_train)
>>> y_pred = reg.predict(X_test)

    phasmanet.PhasmaNetClassifier ¶

    PhasmaNet for binary and multiclass classification (cross-entropy on logits).

    Classification option

    class_weight (None or "balanced": weights inversely proportional to class frequencies in the training split).

    Examples:

    >>> from phasmanet import PhasmaNetClassifier
>>> clf = PhasmaNetClassifier(max_epochs=50, random_state=0).fit(X_train, y_train)
>>> proba = clf.predict_proba(X_test)

    Network and building blocks¶

    phasmanet.PhasmaNet ¶

    Staged spectral token-refinement network for tabular inputs.

    Parameters:

    Name Type Description Default
    input_dim int

    number of input features.

    		 required
    output_dim int

    number of outputs (1 for scalar regression, the number of classes for classification logits).

    		 1
    hidden_dim int

    token width D.

    		 128
    num_tokens int

    number of learned tokens T.

    		 8
    num_stages int

    number of Phi-Stages K.

    		 3
    num_feedback int

    number of Phi-Feedback passes R (0 disables feedback).

    		 2
    heads int

    attention heads per stage (must divide hidden_dim).

    		 4
    dropout float

    dropout rate on residual branches and in the Phi-Refractor.

    		 0.1
    num_refractor_subspaces int

    subspaces in each Phi-Refractor.

    		 4
    use_refractor bool

    set to False for the Phi-Refractor-OFF ablation.

    		 True
    ffn_mult int

    width of the feed-forward block in each stage, as a multiple of hidden_dim.

    		 4
    activation str

    nonlinearity in the feed-forward blocks, the Phi-Refractor and the head (one of ACTIVATIONS).

    		 'gelu'
    attn_dropout float

    dropout on the attention weights.

    		 0.0

    The defaults are the configuration used in the paper.

    forward(x: Tensor) -> torch.Tensor

    pool ¶

    pool(tokens: Tensor) -> torch.Tensor

    Pool the normalised top-level tokens (B, T, D) into one vector (B, D).

    phasmanet.PhiStage ¶

    Transformer encoder layer of a Phi-Stage: multi-head self-attention and a feed-forward block.

    phasmanet.PhiRefractor ¶

    Split each token into subspaces, transform each subspace, recombine with learned gating.

    phasmanet.convert_legacy_state_dict ¶

    convert_legacy_state_dict(state_dict: Dict[str, Tensor]) -> Dict[str, torch.Tensor]

    Rename parameters of checkpoints saved by the research scripts to this module's names.

    The research code used either cascades/prisms/gates/regressor or stage_encoders/refractors/feedback_gates/regressor; both are accepted.
